    One app for the whole dash.

    The React interface, Python hardware service and native receiver run independently of proprietary software. Bluetooth phone services, ELM327 selection and protected car Wi-Fi are managed by the application.

    1. 01

      USB & wireless Android Auto

      Native video, touch input and background phone data, with separate automatic connection and automatic opening settings. Keep the taskbar visible beside Android Auto.

    2. 02

      Your own OBD cockpit

      Arrange blocks, original arc/tick gauges, charts and messages. Define read-only custom sensors and formulas.

    3. 03

      Diagnostic recording

      Manual or automatic capture, configurable intervals and storage limits, and local CSV/JSONL exports.

    4. 04

      Dashboard Studio & glass layouts

      Add, arrange, rename and resize widgets in a live preview. The original dashboard stays the default; glass is optional, with configurable backdrops, accent, opacity, blur and motion.

    5. 05

      Guided introduction

      New profiles get a 19-section spotlight tour of the actual dashboard, shortcuts, customization, Android Auto, audio, OBD, logging and updates. Progress resumes after an interruption.

    6. 06

      Updates in Settings

      GitHub source updates (OTA) with isolated preparation, health checks and rollback, installed manually or automatically when idle.
